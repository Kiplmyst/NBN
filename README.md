# NSN
NSN is a Naturally Simple Notepad that aims to be lightweight and work on any system with ease. It doesn't come bloated with AI or bullshit features, it's a notepad made to let you just write your notes quickly and be done. NSN aims to be snappy and easily compileable on any system.

Coded in C, it's fast and efficient, and it currently uses Raylib for graphics. There's nothing special whatsoever, what it is is in the name.
